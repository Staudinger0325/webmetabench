Acceptance checklist:
## Public acceptance checklist

### R1 - Hero Entrance and Video Lifecycle
When the user opens the page or returns to the top from a lower section, the fixed navigation, MacBook Pro, the "Built for Apple Intelligence." title graphic, the horizontal product video, Buy Now, and the pricing text must appear in sequence within the reserved hero space. The video must play inline and muted from the beginning without displaying controls. The media must pause after the user scrolls away from the video area, restart from the beginning whenever the area re-enters the viewport, and remain on its final frame after playback reaches the end. Repeatedly leaving and returning must not shift the button, pricing text, or heading, and the button's hover style must revert after the pointer leaves.

### R2 - Fixed Navigation and Section Targeting
When the user clicks Store, Mac, iPhone, Watch, Vision, or AirPods, the page must navigate respectively to the product viewer, hero, chip showcase, performance collage, feature showcase, or upgrade highlights, with the navigation remaining fixed at the top while scrolling and the target heading stopping in a readable position below it. Clicking the Apple logo from any lower section must return the user to the top without changing the current color or size. On narrow viewports, after the center links are hidden, the logo and the search and shopping bag icons must retain their original fixed stacking level and positions.

### R3 - Viewer Model Handoff and Dragging
When the user enters the Take a closer look. section and switches between 14-inch and 16-inch sizes, the outgoing model must move sideways and fade out while the target model enters from the side, moves to the center of the canvas, and fades in. Throughout the handoff, the heading, color dots, size buttons, and screen texture must remain in place. After the user presses and drags on the canvas and then releases, the MacBook must retain the adjusted viewing orientation while continuing to use the current size; when reduced motion is not enabled, a slow idle rotation must continue on top of that orientation. Repeatedly clicking the selected size must not start another handoff.

### R4 - Size, Color, and Chassis Synchronization
On the user's first visit to the viewer, it must show the 14-inch MacBook with a dark chassis finish, a ring marking the dark color dot as selected, and the 14-inch button with a white background. Whether the user then selects silver before changing size or keeps the dark finish while switching from 14 inches to 16 inches, a size change must replace only the size and carry the current color forward. After the transition, the centered model's chassis material, the color dot, and the size button must all express the same selection. In the 16-inch state, clicking either silver or dark must update both the chassis and the marker, and clicking the current color must not allow the material and marker to diverge.

### R5 - Chip Mask Scroll Narrative
As the user scrolls down into the Rocket Chip section on a wide viewport, the looping game video must remain pinned in the viewport and continue playing muted while the black Apple-and-M4 mask contracts continuously from an extremely large scale. The heading, description, and two performance comparisons must then fade in in reading order. When scrolling stops, the mask must remain at its current scale. When the user scrolls back up, the mask must enlarge along the same progress path and the text must leave according to the corresponding visibility range; progress must also be reconstructed from the current page position after a rapid pass through the section and return. On a narrow viewport, the media must instead appear directly inside the Apple and M4 outlines followed by the copy, without creating a long pinned section.

### R6 - Continuous Performance Collage Progression
As the user enters the Next-level graphics performance. Game on. section and continues scrolling, the central laptop image must remain the compositional anchor while the surrounding creative-work, image-processing, 3D-production, and game images move continuously along their respective paths into layered positions. The explanatory text must then become readable line by line. After the user stops, reverses, or scrolls rapidly, the image coordinates and text visibility must be determined by the current page position and move backward along the original progress path. On a narrow viewport, the large displacements must be removed and the same images must be scaled into a static collage without causing horizontal page overflow.

### R7 - Feature Model, Card, and Media Synchronization
As the user scrolls down through the See it all in a new light. section, the MacBook in the fixed canvas must rotate continuously around its vertical axis, while the Email AI., Image AI., Summarize AI., AirDrop., and Writing Tool. cards become readable from transparent in that order. The screen must switch to the corresponding feature media before each card appears. If the user stops midway, rapidly crosses multiple items, or scrolls a short distance in reverse, the currently readable card, model orientation, and screen content must all correspond to the same scroll progress. When the screen faces the user again, it must not retain the previous item's media. Once the resources are ready, the canvas must also transition correctly from Loading... to the state for the user's current position.

### R8 - Upgrade Highlight Card Presentation
When the user scrolls into the There’s never been a better time to upgrade. section, the heading, subtitle, and the four performance, Liquid Retina XDR display, Apple Intelligence, and battery-life cards must appear as they enter the viewport. On a wide viewport, the two columns must retain their staggered heights and deep-gray rounded card surfaces. After the user narrows the viewport, the cards must switch to a single column while the scene graphic, all four icons, colorful border, gradient text, and green battery-life emphasis remain with their respective cards. Widening the viewport again must restore the two-column layout without the card reflow clearing the selected viewer state.

### R9 - State Retention Across Viewport Widths
After the user selects the silver 16-inch MacBook on a wide viewport and narrows the window, the text navigation must hide, the product model and canvas must shrink, the chip showcase must leave its long pinned-scroll layout, the performance images must stop making large scroll-driven movements, the feature model must shrink, and the upgrade cards must switch to one column. At the same time, the color dot and size button must continue to show silver and 16 inches. When the user widens the window again, each section must recalculate its canvas dimensions, model scale, mask scrolling, and card column count, while the current selection and scroll position remain in effect instead of returning to the viewer's initial values.

### R10 - Resource Preparation and Session Reset
If the user enters the page before all fonts, images, videos, or 3D models are ready, the black stage, fixed navigation, headings, and reserved media or canvas areas must be established first. The feature canvas may display Loading..., and arriving resources must fill their original positions and present the model, cards, and screen content according to the current scroll progress. During the same visit, the selected color and size must persist while the user navigates, scrolls back, and resizes the viewport. Only a full refresh or reconstruction of the page may return it to the top, the dark 14-inch MacBook, and the start of the feature sequence, without carrying over the earlier media progress.

### R11 - Footer Completion and Reverse Browsing
After the user scrolls beyond the upgrade cards, the shopping assistance text, Apple logo, copyright line generated from the current runtime year, and the Privacy Policy, Terms of Use, Sales Policy, Legal, and Site Map links must become readable line by line against the black background. Hovering over a link must change only the emphasis of that link's text. When the user moves upward from the footer, the upgrade cards, feature model and cards, performance collage, and chip mask must restore their respective states from the current scroll position. The footer leaving the viewport must not clear the viewer color and size selected during the current session.
